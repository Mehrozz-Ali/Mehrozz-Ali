## 👨‍💻 About Me

I'm a Full Stack Developer specializing in the **MERN stack** and **Next.js**, with a strong focus on **TypeScript** for building reliable, maintainable applications. I work across the entire stack — designing responsive, accessible UIs with React and Tailwind CSS, building type-safe server-side logic with Next.js App Router, and architecting secure RESTful APIs with Node.js and Express.

I care about clean architecture, strong typing, and code that scales — not just code that works. Currently deep in building an LMS platform with social authentication, Redux Toolkit state management, and a fully typed API layer.

- 🔭 Currently building: a full-featured **E-Learning Platform** (Next.js, TypeScript, NextAuth, Redux Toolkit)
- 🌱 Currently sharpening: advanced TypeScript patterns, Next.js Server Actions, and system design
- 💬 Ask me about: React/Next.js, TypeScript, REST API design, MongoDB & Mongoose
- ⚡ Fun fact: I'd rather fix a type error than debug it in production
